# API

Authentication: POST /api/v1/auth/register, POST /api/v1/auth/login, GET /api/v1/auth/me
Privacy: POST /api/v1/privacy/analyze, POST /api/v1/privacy/sanitize
Chat: POST /api/v1/chat
Events: GET /api/v1/events, GET /api/v1/events/{id}
Policies: GET /api/v1/policies, PUT /api/v1/policies/{entity_type}
Admin: GET /api/v1/admin/statistics
Health: GET /api/v1/health
